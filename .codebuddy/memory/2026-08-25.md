# 2026-08-25

## 将 agent/ 改造为 TypePHP 程序（mode: bin）
- 新增 `agent/project.yml`：`mode: bin`, `sources: [src]`, `output: binlog-agent`。目录编译会扫描全部 .php，故 sources 只列 src/，把纯 PHP 辅助脚本 `bin/agent`、`bin/mysqlbinlog_dump.php` 排除在编译外（它们用 getopt/require/class_exists，不可编译，且 mysqlbinlog_dump 由 proc_open 以 php 运行）。
- 新增 `agent/src/main.php`：全局 `function main(int $argc, array $argv)`（无命名空间，TypePHP bin 入口需全局 main），解析 `--host/--port`，启动 `Server`。替代原 `bin/agent`。
- 消除闭包（TypePHP 子集禁止 closures/arrow functions）：
  - `AgentHandler`：三个 `?\Closure` 回调属性（sseWriter/responder/pipeRegister）改为单个 `?ClientConn $client`，新增 `setClient()`；`sse/respondOnceJson/registerDumpPipe` 改为调用 ClientConn 方法。
  - `Router::handle`：签名改为 `(HttpRequest $req, ClientConn $c)`，去掉两个 callable 参数及内部闭包，直接 `$c->respond(...)` / `$c->beginSse()`。
  - `Server::dispatch`：去掉闭包，改 `$router->handle($req, $c)`；新增 `registerDumpPipe($pipe, ?AgentHandler)`（原 pipeRegister 闭包逻辑）；`tick` 的 arrow fn `array_filter` 改为 `filterReadable()` 辅助方法；`new ClientConn($conn,$peer,$this)` 传入 Server 引用。
  - `ClientConn`：新增 `cors` 属性 + `corsHeaders()`、`registerDumpPipe()`（转发到 Server）、构造函数新增 `?Server $server`；`respond` 的 headers 缺省为 cors。
- 验证：11 个 src 文件 `php -l` 全通过；`main(help)` 输出正常；`serve --port 8099` 后台启动后 POST /connect 返回正确 v2 错误帧（code 1008）。
- 注意：`bin/mysqlbinlog_dump.php` 用 `PHP_BINARY` 启动，编译后的二进制里 PHP_BINARY 是二进制自身而非 php，真实 dump 需 php 解释器——运行时注意（未改，属已知行为）。
